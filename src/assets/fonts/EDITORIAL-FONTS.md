# Editorial font provenance

Added for MEE-11 on 13 October 2026. Inter and Newsreader Latin variable normal WOFF2 files were extracted from @fontsource-variable/inter@5.3.0 and @fontsource-variable/newsreader@5.3.0 npm packages, respectively. Their complete package LICENSE files are retained as inter-OFL.txt and newsreader-OFL.txt. These are SIL Open Font License fonts; preserve the notices when distributing the website.

Inter: weights 100–900. Newsreader: weights 200–800, variable optical size. next/font/local serves the files with swap and system/Georgia fallbacks. No package dependency or runtime font CDN was added. Earlier Manrope and Bricolage files/notices are retained for provenance and reversible history.
