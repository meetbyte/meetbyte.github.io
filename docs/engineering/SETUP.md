## Automation boundaries
- No unattended merges or deployment approvals.
- `.github/workflows/agent-pr.yml` has permissions to create PRs and dispatch CI; it does NOT approve or merge changes. Only trusted collaborators/authorized agents should be able to push `agent/**` branches.
- Bot-created PRs might not trigger `pull_request` CI because GitHub suppresses events generated by its built-in token. The agent workflow dispatches CI explicitly once installed on the default branch.
- `AGENTS.md` and `docs/engineering/APPROVAL-POLICY.md` remain authoritative for Agent work boundaries.
- GitHub's required codeowner review only applies after a CODEOWNERS file exists on the protected base branch and the ruleset requires it.
- CI and PR evidence are necessary, but not sufficient to replace owner approval.
